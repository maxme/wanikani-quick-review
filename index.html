WaniKani Quick Review

Sign in

Enter your WaniKani API token. A read-only token is enough. It stays in this browser (localStorage) and is only sent to api.wanikani.com.

Create a token at wanikani.com → Settings → API Tokens.

Filters

Selected chips of one group add up (N5 + N4); groups combine (N5 + N4 that you missed this week). No chip selected means no constraint. Every filter applies at once; the number on a chip is how many items it matches with the other filters.
